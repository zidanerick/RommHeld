# Project status

RommHeld is transitioning from a Vita-focused prototype into a multi-device RomM handheld manager.

Current work:

- PlayStation Vita USB/VitaShell workflow
- modular application structure
- Vita Setup information
- generic Send File workflow on the Vita backend
- device/backend architecture

Next device:

- Nintendo 3DS over FTP

The 3DS work should extend the existing application rather than create a separate manager. Emulator installation remains upstream-project driven, with RommHeld providing links and generic file transfer instead of maintaining a package mirror.
